Use [Copilot](/features/copilot) from Home or the workflow editor for conversations and workflow actions. The former standalone Assistant chat and Chat routes now open Home; they are not separate active chat runtimes.

## Saved configuration

Assistant profile, context, skills, permission, and activity settings remain available at `/assistant/settings`. Existing configuration records are retained. Their presence does not mean a separate Assistant chat is running or that every saved option changes the active Copilot runtime.

Use the controls exposed in Copilot for current conversations, attachments, resource references, and workflow actions. Workflow AI nodes have their own model and tool configuration.
