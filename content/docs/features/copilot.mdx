Copilot is Innflow's workflow-building assistant. Use it from Home to turn a request into a new workflow or table, or inside the editor to understand and change the workflow already on the canvas.

## Home

The Home composer is the fastest way to start. Describe the system you want, select relevant apps, and attach workspace resources, files, or pasted text. Copilot can draft a workflow or table and hand it into the appropriate editor for review.

You can choose a chat model, dictate a prompt with the microphone, and continue the same conversation as generated artifacts appear.

## Editor Copilot

Open Copilot from the workflow editor to work against the live canvas. It receives a redacted snapshot of the workflow's nodes, connections, and configuration so its suggestions stay grounded in the current state.

## Context Aware Suggestions

When you open the Copilot, it reads your current workflow state (what nodes you have, how they are connected, what is configured) and tailors its suggestions. For example:

- **Empty workflow:** "Add a trigger to get started" or "Build a workflow from a description"
- **Has trigger, no actions:** "Add an AI node to process the input" or "Connect to Slack to send notifications"
- **Complete workflow:** "Run the workflow" or "Add error handling"

## Context and continuity

Copilot supports:

- Separate conversation threads
- File and pasted-text attachments
- App and workspace-resource references
- Model selection
- Voice dictation
- Persistent conversation history
- Relevant saved preferences and corrections
- Visible activity and tool traces for actions it takes
- Positive or negative response feedback

Live workflow state takes precedence over saved conversation memory.

## Test & Repair

When Test & Repair is enabled for the deployment, Copilot can start a real workflow execution after you approve the warning. A session can make up to three real attempts and can automatically change only explicitly safe configuration fields.

<Callout type="warning">
  Test & Repair runs are real executions. They can send messages, update external systems, and consume credits. Structural changes, credentials, destinations, operations, schedules, deployment state, and other sensitive changes require separate confirmation.
</Callout>

<Callout type="info">
  Copilot availability and advanced capabilities depend on your plan and workspace configuration.
