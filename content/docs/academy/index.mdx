Innflow brings visual workflows, AI, and workspace data into one place. You connect the steps of a process, choose the information each step needs, and inspect what happens when it runs.

<WorkflowMap />

## Start with the work

Think of a request that arrives repeatedly: a customer question, a new lead, or a document to review. A workflow turns that request into a sequence of actions. A trigger starts a run, nodes do the work, and connections determine what happens next.

For example, a form can collect a request, a Condition can choose a path, and a communication node can notify the right person. Start with one small outcome before adding more branches.

## Your workspace holds the context

**Tables** store structured records. **Files** hold documents and media. **Knowledge bases** make material available for retrieval. Workflows can use these resources through the operations and permissions available in your workspace.

Connected accounts let your workflows reach other tools. Set up credentials for the service you need, then select that connection in the appropriate node.

## How to use this Academy

Follow the lessons in the sidebar, or jump to the topic you need. Each lesson explains a concept, gives you something to try, and links to the detailed reference. The use cases bring several concepts together.

### Do I need to write code?

You can build workflows visually. Variables let you connect outputs to inputs without writing a program. API and CLI documentation is available separately when you need programmatic control.

### Should I start with Copilot?

Copilot can help build and explain workflows. Learning the trigger, node, and output model makes it easier to review what it creates and troubleshoot a run.
