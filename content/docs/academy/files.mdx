<LearningGoals>
- Distinguish a file from text extracted from that file.
- Check access and format requirements before processing.
</LearningGoals>

## Start with the source file

Files are workspace resources for documents and media. A workflow step may need a file reference, a URL, or extracted text. These are different inputs; check the receiving node's fields rather than treating them as interchangeable.

## Prepare the right input

A text prompt does not automatically read the contents of a document merely because it contains the file name. Use an operation that accepts the file format or extracts the required text, then pass the result onward.

## Check access

Confirm the workflow can access the file and that any link remains valid when execution happens. Only send content to a connected provider when it is appropriate for that process.

## Try it

Use a small sample document with no sensitive data. Inspect the file or extraction step's output, then select the correct value for the next action.
