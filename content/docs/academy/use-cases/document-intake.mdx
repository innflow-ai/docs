</LearningGoals>

## The process

Start with a small sample file accessible to your workflow. Choose an operation that supports the document format and returns the information you need.

1. Obtain the source file or its supported reference.
2. Extract the text or fields using a compatible operation.
3. Check that required fields are present.
4. Write the result and source reference to a table.
5. Route incomplete results for review.

## Preserve uncertainty

An extracted date or amount can be missing or ambiguous. Do not silently replace it with a guessed value. Keep the source available so a person can check the result.

## Validate the result

Test a clear document and one with missing information. Inspect the extracted fields and confirm that the incomplete example follows the review path.
