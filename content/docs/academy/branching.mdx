## Use a rule when the answer is exact

A Condition node branches based on configured conditions. Use rule-based conditions for facts such as a status, a numeric threshold, or the presence of a value. Connect the branch outputs to the actions that should follow.

## Use AI deliberately

New Condition nodes use typed rules and fixed If/Else branches. Use Router when a decision depends on text meaning. Earlier workflows may still contain LLM-based Condition settings; that legacy form is not the default for new nodes.

AI Decision is a separate capability with availability controls. If it is enabled for your workspace, read its [reference](/tools/ai-decision) before building around its Decided and Needs review outputs.

## Try it

Create a rule that routes a sample record based on its status. Test an input that matches and another that does not. Confirm which connected node actually runs in the execution details.
