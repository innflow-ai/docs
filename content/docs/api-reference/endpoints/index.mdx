## Scope

This reference covers every customer-facing route under `/api/v1`, including authoring and discovery. `/api/v1/portal-events` is service-to-service ingestion and does not accept customer API keys. Provider callbacks, internal service APIs, browser-session routes and tRPC are separate interfaces, not general customer REST endpoints. See [triggers](/triggers) for workflow-specific webhook setup and [MCP](/mcp) for the MCP interface.
