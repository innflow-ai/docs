---
title: 'Search node types'
description: 'GET /mcp/node-types'
---

Discover available node types and operations before creating graph nodes.


```http
GET /api/v1/mcp/node-types
```

**Permission:** `workflows:read`. Write endpoints also require a workspace role that permits changes. See [authentication](/api-reference/authentication) and [errors](/api-reference/errors).

## Request

```bash
curl --request GET 'https://app.innflow.ai/api/v1/mcp/node-types' \
  --header "Authorization: Bearer $INNFLOW_API_KEY"
```

Examples use placeholder IDs. Set `INNFLOW_API_KEY` in your shell and replace IDs with your own before sending a request.

## Parameters

| Name | In | Required | Details |
| --- | --- | --- | --- |
| `X-Innflow-Workspace` | header | No | Organization ID, or personal. Set explicitly; omission uses legacy user-owned resource scope. |
| `page` | query | No | Page number, starting at 1. |
| `pageSize` | query | No | Results per page (1–100). |
| `search` | query | No | Search the node catalog. |

## Response

**HTTP 200** — Returns data with items, totalCount, nextPage and contractVersion. Each item describes type, name, description, category, authMode and operations.

See [OpenAPI download](/openapi.json) for the machine-readable request contract and [errors](/api-reference/errors) for errors and retry behavior.
