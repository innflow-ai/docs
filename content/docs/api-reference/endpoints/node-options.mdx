---
title: 'Get node field options'
description: 'GET /workflows/{workflowId}/node-options'
---

Resolve options for a field on a saved node. Some dynamic provider selectors require opening the editor.


```http
GET /api/v1/workflows/{workflowId}/node-options
```

**Permission:** `workflows:read`. Write endpoints also require a workspace role that permits changes. See [authentication](/api-reference/authentication) and [errors](/api-reference/errors).

## Request

```bash
curl --request GET 'https://app.innflow.ai/api/v1/workflows/workflow_id/node-options?nodeId=node_id&field=field_name' \
  --header "Authorization: Bearer $INNFLOW_API_KEY"
```

Examples use placeholder IDs. Set `INNFLOW_API_KEY` in your shell and replace IDs with your own before sending a request.

## Parameters

| Name | In | Required | Details |
| --- | --- | --- | --- |
| `workflowId` | path | Yes | Resource identifier. |
| `X-Innflow-Workspace` | header | No | Organization ID, or personal. Set explicitly; omission uses legacy user-owned resource scope. |
| `nodeId` | query | Yes | Saved node ID. |
| `field` | query | Yes | Field name from the node schema. |
| `search` | query | No | Case-insensitive label filter. |
| `cursor` | query | No | Nonnegative option offset. |

## Response

**HTTP 200** — Returns data with items (id and label), nextCursor and optional handoffUrl. Up to 100 options are returned. Follow handoffUrl when remote options require the editor.

See [OpenAPI download](/openapi.json) for the machine-readable request contract and [errors](/api-reference/errors) for errors and retry behavior.
