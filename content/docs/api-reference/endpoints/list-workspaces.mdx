---
title: 'List workspaces'
description: 'GET /workspaces'
---

List the personal workspace and organizations you belong to.


```http
GET /api/v1/workspaces
```

**Permission:** `workspaces:read`. Write endpoints also require a workspace role that permits changes. See [authentication](/api-reference/authentication) and [errors](/api-reference/errors).

## Request

```bash
curl --request GET 'https://app.innflow.ai/api/v1/workspaces' \
  --header "Authorization: Bearer $INNFLOW_API_KEY"
```

Examples use placeholder IDs. Set `INNFLOW_API_KEY` in your shell and replace IDs with your own before sending a request.

## Parameters

| Name | In | Required | Details |
| --- | --- | --- | --- |
| `X-Innflow-Workspace` | header | No | Organization ID, or personal. Set explicitly; omission uses legacy user-owned resource scope. |

## Response

**HTTP 200** — Returns data as an array. Each entry has id, name, type and role; organization entries also include slug.

See [OpenAPI download](/openapi.json) for the machine-readable request contract and [errors](/api-reference/errors) for errors and retry behavior.
