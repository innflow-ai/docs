All Google Suite nodes require a **Google OAuth connection**. Connect your Google account from [Credentials](https://app.innflow.ai/credentials).

## Google Sheets

Read from or write to Google Sheets spreadsheets.

**Operations:**

- **Read Rows** (`READ_ROWS`) — Read rows from a spreadsheet
- **Append Rows** (`APPEND_ROWS`) — Append rows to a spreadsheet
- **Update Rows** (`UPDATE_ROWS`) — Update existing rows in a spreadsheet
- **Create Spreadsheet** (`CREATE_SPREADSHEET`) — Create a new Google Sheets spreadsheet

**Configuration:**

| Field | Description |
|-------|-------------|
| **Spreadsheet ID** | The ID from the Google Sheets URL |
| **Range** | Cell range in A1 notation (e.g., `Sheet1!A1:D10`) |
| **Values** | Data to write (for Append/Update operations) |

[All operations and configuration fields](/tools/reference#google-sheets).

## Google Docs

Create and read Google Docs documents, or write content to an existing document.

**Operations:**

- **Create Document** (`CREATE_DOCUMENT`) — Create a new Google Docs document
- **Read Document** (`READ_DOCUMENT`) — Read content from a Google Docs document
- **Write to Document** (`WRITE_TO_DOCUMENT`) — Write content to an existing Google Docs document

**Configuration:**

| Field | Description |
|-------|-------------|
| **Document ID** | The ID of the document (for Read/Write) |
| **Title** | Document title (for Create) |
| **Content** | Document content |

[All operations and configuration fields](/tools/reference#google-docs).

## Google Calendar

List calendars and create, read, update, or delete events in Google Calendar.

**Operations:**

- **List Calendars** (`LIST_CALENDARS`) — List all calendars for the authenticated user
- **List Events** (`LIST_EVENTS`) — List events from a calendar with optional search
- **Create Event** (`CREATE_EVENT`) — Create a new calendar event
- **Read Event** (`READ_EVENT`) — Get details of a specific event
- **Update Event** (`UPDATE_EVENT`) — Update an existing calendar event
- **Delete Event** (`DELETE_EVENT`) — Delete a calendar event

**Configuration:**

| Field | Description |
|-------|-------------|
| **Calendar ID** | Which calendar to use (default: `primary`) |
| **Title** | Event title (for Create) |
| **Start Time** | Event start in ISO 8601 format |
| **End Time** | Event end in ISO 8601 format |

[All operations and configuration fields](/tools/reference#google-calendar).

**Configuration:**

| Field | Description |
|-------|-------------|

## Google Groups

List, read, create, update, or delete groups and manage members, roles, and membership checks.

**Requires:** Google OAuth connection with admin access

**Operations:**

- **List Groups** (`LIST_GROUPS`) — List all groups
- **Get Group** (`GET_GROUP`) — Get group details
- **Create Group** (`CREATE_GROUP`) — Create a new group
- **Update Group** (`UPDATE_GROUP`) — Update group settings
- **Delete Group** (`DELETE_GROUP`) — Delete a group
- **List Members** (`LIST_MEMBERS`) — List group members
- **Get Member** (`GET_MEMBER`) — Get member details
- **Add Member** (`ADD_MEMBER`) — Add a member to a group
- **Update Member Role** (`UPDATE_MEMBER_ROLE`) — Change a member's role
- **Remove Member** (`REMOVE_MEMBER`) — Remove a member from a group
- **Check Membership** (`CHECK_MEMBERSHIP`) — Check if a user is a member of a group

[All operations and configuration fields](/tools/reference#google-groups).
