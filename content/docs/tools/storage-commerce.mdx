## Dropbox

Upload, download, list, and share files through Dropbox. Use Dropbox when a workflow needs to move generated files, collect attachments, or create shareable links.

**Common uses:**
- Upload generated reports or CSV exports
- Download source files for processing
- List files in a folder
- Create shared links for downstream messages

**Requires:** Dropbox OAuth connection

**Operations:**

- **Upload File** (`UPLOAD_FILE`) — Upload a file to Dropbox
- **Download File** (`DOWNLOAD_FILE`) — Download a file from Dropbox
- **List Folder** (`LIST_FOLDER`) — List contents of a folder
- **Create Folder** (`CREATE_FOLDER`) — Create a new folder
- **Delete** (`DELETE`) — Delete a file or folder
- **Copy** (`COPY`) — Copy a file or folder
- **Move** (`MOVE`) — Move a file or folder
- **Get Metadata** (`GET_METADATA`) — Get file or folder metadata
- **Create Shared Link** (`CREATE_SHARED_LINK`) — Create a shared link for a file
- **Search Files** (`SEARCH_FILES`) — Search for files in Dropbox

[All operations and configuration fields](/tools/reference#dropbox).

## Shopify

**Common uses:**

- Pull order details into support or fulfillment workflows

**Requires:** Shopify connection

- **Delete Product** (`DELETE_PRODUCT`) — Delete a product

- **Cancel Order** (`CANCEL_ORDER`) — Cancel an order

- **List Customers** (`LIST_CUSTOMERS`) — List all customers
- **Update Customer** (`UPDATE_CUSTOMER`) — Update an existing customer

**Common uses:**

- Pull link analytics into reporting workflows

**Requires:** Dub credentials

**Operations:**

- **Create Short Link** (`CREATE_SHORT_LINK`) — Shorten a URL into a Dub link
- **Get Link Analytics** (`GET_LINK_ANALYTICS`) — Fetch click analytics for a link over a time range
- **List Links** (`LIST_LINKS`) — List links in the connected workspace
- **Update Link** (`UPDATE_LINK`) — Update destination URL or metadata
- **Delete Link** (`DELETE_LINK`) — Permanently delete a short link
