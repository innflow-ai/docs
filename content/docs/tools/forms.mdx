## Typeform

The Typeform action node manages forms and reads response data through the Typeform API.

**Operations:**

- **List Forms** (`LIST_FORMS`) — List all forms in your Typeform account
- **Get Form** (`GET_FORM`) — Get the full definition of a specific form
- **Create Form** (`CREATE_FORM`) — Create a new Typeform form with fields and settings
- **Update Form** (`UPDATE_FORM`) — Update an existing form with a new definition
- **Delete Form** (`DELETE_FORM`) — Permanently delete a form
- **Get Responses** (`GET_RESPONSES`) — Retrieve form responses with optional date range filtering
- **Get Form Insights** (`GET_FORM_INSIGHTS`) — Get analytics and insights for a form

Use the [Typeform Trigger](/triggers#typeform-trigger) when a new response should start the workflow.

**Requires:** Typeform credentials

[All operations and configuration fields](/tools/reference#typeform).

## Google Forms

The Google Forms action node retrieves responses from a connected Google Form. See [Google Suite](/tools/google-suite#google-forms) for configuration details.

Use the [Google Forms Trigger](/triggers#google-forms-trigger) when each new submission should start a workflow.

**Requires:** Google OAuth connection

**Operations:**

- **Get Responses** (`GET_RESPONSES`) — Retrieve responses from a Google Form

[All operations and configuration fields](/tools/reference#google-forms).

## Innflow Forms

The [Form Trigger](/triggers#form-trigger) publishes a form backed by an Innflow workflow. Use it for intake flows where people outside your workspace need to submit structured data without a separate form provider.

The workflow must be deployed before its public form can execute.
