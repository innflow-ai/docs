## Airtable

Read from or write to Airtable bases. Use Airtable as a lightweight database for your workflows.

**Operations:**

- **List Records** (`LIST_RECORDS`) — List records from a table
- **Read Record** (`READ_RECORD`) — Read a single record by ID
- **Create Record** (`CREATE_RECORD`) — Create a new record in a table
- **Update Record** (`UPDATE_RECORD`) — Update an existing record
- **Delete Record** (`DELETE_RECORD`) — Delete a record by ID

**Configuration:**

| Field | Description |
|-------|-------------|
| **Base ID** | Your Airtable base identifier |
| **Table ID** | The specific table within the base |
| **Fields** | Record field values (for Create/Update) |

**Requires:** Airtable OAuth connection

[All operations and configuration fields](/tools/reference#airtable).

## HubSpot

Create, read, update, delete, list, and search HubSpot contacts, companies, deals, and other supported CRM records.

**Requires:** HubSpot OAuth connection

**Operations:**

- **Create Record** (`CREATE_RECORD`) — Create a new CRM record
- **Read Record** (`READ_RECORD`) — Read a single record by ID
- **Update Record** (`UPDATE_RECORD`) — Update an existing record
- **Delete Record** (`DELETE_RECORD`) — Delete a record by ID
- **List Records** (`LIST_RECORDS`) — List records with optional limit
- **Search Records** (`SEARCH_RECORDS`) — Search records with query or filters

[All operations and configuration fields](/tools/reference#hubspot).

## Attio

Manage Attio CRM records, notes, tasks, and object metadata.

**Common operations:**

- List, get, search, update, delete, or assert records
- Create, read, list, and delete notes
- Create and list tasks
- Read object metadata

**Requires:** Attio connection

**Operations:**

- **List Records** (`LIST_RECORDS`)
- **Get Record** (`GET_RECORD`)
- **Update Record** (`UPDATE_RECORD`)
- **Delete Record** (`DELETE_RECORD`)
- **Search Records** (`SEARCH_RECORDS`)
- **Assert Record** (`ASSERT_RECORD`)
- **List Notes** (`LIST_NOTES`)
- **Get Note** (`GET_NOTE`)
- **Create Note** (`CREATE_NOTE`)
- **Delete Note** (`DELETE_NOTE`)
- **List Tasks** (`LIST_TASKS`)
- **Create Task** (`CREATE_TASK`)
- **Get Object** (`GET_OBJECT`)

## Apollo

Search and enrich people or organizations, perform bulk enrichment, and create or update Apollo contacts.

**Requires:** Apollo API credentials

**Operations:**

- **Search People** (`SEARCH_PEOPLE`) — Search for people by title, location, seniority, and company
- **Enrich Person** (`ENRICH_PERSON`) — Get detailed info about a person by email, name, or LinkedIn
- **Bulk Enrich People** (`BULK_ENRICH_PEOPLE`) — Enrich multiple people at once from a JSON array
- **Search Organizations** (`SEARCH_ORGANIZATIONS`) — Search for companies by location, size, and keywords
- **Enrich Organization** (`ENRICH_ORGANIZATION`) — Get detailed info about a company by domain
- **Bulk Enrich Organizations** (`BULK_ENRICH_ORGANIZATIONS`) — Enrich multiple organizations by domain
- **Create Contact** (`CREATE_CONTACT`) — Create a new contact in Apollo CRM
- **Update Contact** (`UPDATE_CONTACT`) — Update an existing contact by ID
- **Search Contacts** (`SEARCH_CONTACTS`) — Search contacts in your Apollo CRM
- **Bulk Create Contacts** (`BULK_CREATE_CONTACTS`) — Create multiple contacts from a JSON array

[All operations and configuration fields](/tools/reference#apollo).
