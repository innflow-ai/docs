## Slack

Send messages to Slack channels or read recent messages from a channel.

**Operations:**

- **Send Message** (`SEND_MESSAGE`) — Send a message to a channel
- **Read Messages** (`READ_MESSAGE`) — Read recent messages from a channel
- **Create Canvas** (`CREATE_CANVAS`) — Listed in search, but the current Innflow implementation rejects this operation.

**Configuration:**

| Field | Description |
|-------|-------------|
| **Operation** | Send Message, Read Messages, or Create Canvas |
| **Channel** | The Slack channel to target |
| **Content** | Message text or the content required by the selected operation; supports template variables. |

**Availability:** Create Canvas is discoverable but is not executable in the current Innflow implementation. Use Send Message or Read Messages for working Slack actions.

**Requires:** Slack OAuth connection

[All operations and configuration fields](/tools/reference#slack).

## Gmail

Send, read, draft, search, move, mark, and archive email through Gmail.

**Operations:**

- **Send Email** (`SEND_EMAIL`) — Send an email from your Gmail account
- **Read Emails** (`READ_EMAILS`) — Read emails from a label/folder
- **Draft Email** (`DRAFT_EMAIL`) — Create a draft email
- **Search Emails** (`SEARCH_EMAILS`) — Search emails using Gmail query syntax
- **Move Email** (`MOVE_EMAIL`) — Move an email by adding/removing labels
- **Mark as Read** (`MARK_AS_READ`) — Mark a message as read
- **Mark as Unread** (`MARK_AS_UNREAD`) — Mark a message as unread
- **Archive Email** (`ARCHIVE_EMAIL`) — Archive an email (remove from inbox)

**Configuration (Send Email):**

| Field | Description |
|-------|-------------|
| **To** | Recipient email address |
| **Subject** | Email subject line |
| **Body** | Email body (HTML supported) |

**Requires:** Google OAuth connection

[All operations and configuration fields](/tools/reference#gmail).

## Microsoft Outlook

Send, read, draft, and search email through Microsoft Outlook.

**Operations:**

- **Send Email** (`SEND_EMAIL`) — Send an email from your Outlook account
- **Read Emails** (`READ_EMAILS`) — Read emails from a folder
- **Read Email** (`READ_EMAIL`) — Read a single email by ID
- **Create Draft** (`CREATE_DRAFT`) — Create a draft email
- **Search Emails** (`SEARCH_EMAILS`) — Search emails using a query

**Configuration (Send Email):**

| Field | Description |
|-------|-------------|
| **To** | Recipient email address |
| **Subject** | Email subject line |
| **Body** | Email body |

**Requires:** Microsoft OAuth connection

[All operations and configuration fields](/tools/reference#microsoft-outlook).

## Microsoft Teams

Send or read channel messages, list teams and channels, and create a channel.

**Operations:**

- **Send Message** (`SEND_MESSAGE`) — Send a message to a Teams channel
- **Read Messages** (`READ_MESSAGES`) — Read recent messages from a channel
- **List Channels** (`LIST_CHANNELS`) — List channels in a team
- **List Teams** (`LIST_TEAMS`) — List all teams you belong to
- **Create Channel** (`CREATE_CHANNEL`) — Create a new channel in a team

**Configuration:**

| Field | Description |
|-------|-------------|
| **Channel** | The Teams channel to post to |
| **Content** | Message text |

**Requires:** Microsoft OAuth connection

[All operations and configuration fields](/tools/reference#microsoft-teams).

## Telegram

Send messages, photos, videos, audio, animations, or documents through Telegram, and delete messages when needed. To start a workflow from incoming bot messages, use the [Telegram Trigger](/triggers#telegram-trigger).

**Operations:**

- **Send Message** (`SEND_MESSAGE`)
- **Send Photo** (`SEND_PHOTO`)
- **Send Video** (`SEND_VIDEO`)
- **Send Audio** (`SEND_AUDIO`)
- **Send Animation** (`SEND_ANIMATION`)
- **Send Document** (`SEND_DOCUMENT`)
- **Delete Message** (`DELETE_MESSAGE`)

**Configuration:**

| Field | Description |
|-------|-------------|
| **Bot token** | Telegram bot token |
| **Chat ID** | The Telegram chat, channel, or group to message |
| **Content** | Message text |

[All operations and configuration fields](/tools/reference#telegram).

## Resend

Send transactional emails using the Resend email API.

**Operations:**

- **Send Email** (`SEND_EMAIL`)

**Configuration:**

| Field | Description |
|-------|-------------|
| **To** | Recipient email address |
| **Subject** | Email subject |
| **Body** | Email body (HTML supported) |

Resend is a good choice when you need to send emails from a custom domain without connecting a personal Gmail or Outlook account.

[All operations and configuration fields](/tools/reference#resend).
