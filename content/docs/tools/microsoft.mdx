All Microsoft nodes require a **Microsoft OAuth connection**. Connect your Microsoft account from [Credentials](https://app.innflow.ai/credentials).

## Microsoft Excel

Read from or write to Excel files stored in OneDrive.

**Operations:**

- **Create Spreadsheet** (`CREATE_SPREADSHEET`) — Create a new Microsoft Excel spreadsheet
- **Read Rows** (`READ_ROWS`) — Read rows from an Excel spreadsheet
- **Write Rows** (`WRITE_ROWS`) — Write rows to an Excel spreadsheet

**Configuration:**

| Field | Description |
|-------|-------------|
| **Workbook ID** | The Excel workbook in OneDrive |
| **Range** | Cell range to read or write |

[All operations and configuration fields](/tools/reference#microsoft-excel).

## Microsoft Word

Create, read, or write Word documents stored in OneDrive.

**Operations:**

- **Create Document** (`CREATE_DOCUMENT`) — Create a new Microsoft Word document
- **Read Document** (`READ_DOCUMENT`) — Read content from a Microsoft Word document
- **Update Document** (`UPDATE_DOCUMENT`) — Update content in an existing Microsoft Word document

**Configuration:**

| Field | Description |
|-------|-------------|
| **Document ID** | The document to read (for Read) |
| **Title** | Document title (for Create) |
| **Content** | Document content |

[All operations and configuration fields](/tools/reference#microsoft-word).

## Microsoft OneDrive

List and retrieve files, create folders, or delete files in OneDrive.

**Operations:**

- **List Files** (`LIST_FILES`) — List files in a OneDrive folder
- **Get File** (`GET_FILE`) — Get a file from OneDrive
- **Create Folder** (`CREATE_FOLDER`) — Create a new folder in OneDrive
- **Delete File** (`DELETE_FILE`) — Delete a file from OneDrive

**Configuration:**

| Field | Description |
|-------|-------------|
| **Folder ID** | Target folder for listing or creation |
| **File ID** | Specific file for retrieval or deletion |

[All operations and configuration fields](/tools/reference#microsoft-onedrive).

## Microsoft Planner

List plans and tasks, then create, update, or delete Planner tasks.

**Requires:** Microsoft OAuth connection

**Operations:**

- **List Plans** (`LIST_PLANS`) — List all plans in the group
- **List Tasks** (`LIST_TASKS`) — List tasks in a plan
- **Create Task** (`CREATE_TASK`) — Create a new task in a plan
- **Update Task** (`UPDATE_TASK`) — Update an existing task
- **Delete Task** (`DELETE_TASK`) — Delete a task

[All operations and configuration fields](/tools/reference#microsoft-planner).

## Microsoft SharePoint

List sites and lists, read list items, and create or update list items in SharePoint Online.

**Requires:** Microsoft OAuth connection

**Operations:**

- **List Sites** (`LIST_SITES`) — Search or list SharePoint sites
- **List Lists** (`LIST_LISTS`) — List all lists in a SharePoint site
- **Get List Items** (`GET_LIST_ITEMS`) — Get items from a SharePoint list
- **Create List Item** (`CREATE_LIST_ITEM`) — Create a new item in a SharePoint list
- **Update List Item** (`UPDATE_LIST_ITEM`) — Update an existing item in a SharePoint list

[All operations and configuration fields](/tools/reference#microsoft-sharepoint).
