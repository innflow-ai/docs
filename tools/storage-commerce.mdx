## Dropbox

Upload, download, list, and share files through Dropbox. Use Dropbox when a workflow needs to move generated files, collect attachments, or create shareable links.

**Common uses:**
- Upload generated reports or CSV exports
- Download source files for processing
- List files in a folder
- Create shared links for downstream messages

**Requires:** Dropbox OAuth connection

---

## Shopify

Work with Shopify store data including products, orders, customers, and inventory.

**Common uses:**
- Create or update products from internal data
- Pull order details into support or fulfillment workflows
- Look up customers before sending personalized messages
- Sync inventory events into other systems

**Requires:** Shopify connection

---

## LinkedIn

Publish LinkedIn posts and retrieve profile data.

**Common uses:**
- Draft and publish social posts from approved content
- Pull profile information into enrichment workflows
- Route social actions through approval steps before publishing

**Requires:** LinkedIn OAuth connection

See [Social Publishing](/tools/social-publishing) for every supported publishing channel.

## PostHog

Capture events and work with PostHog analytics resources including event definitions, people, HogQL queries, insights, dashboards, cohorts, feature flags, experiments, surveys, session recordings, property definitions, projects, and organizations.

**Common uses:**
- List projects and inspect analytics metadata
- Retrieve property definitions
- Update property definitions as part of data hygiene workflows
- Combine product analytics context with CRM or support automation

**Requires:** PostHog API credentials

---

## Dub

Create and manage short links with Dub.co.

**Common uses:**
- Create branded short links for campaigns
- Pull link analytics into reporting workflows
- Generate links before sending outbound messages

**Requires:** Dub credentials

---

## ElevenLabs

Convert text into speech with ElevenLabs.

**Common uses:**
- Generate voiceovers from approved scripts
- Create audio summaries from documents
- Turn workflow output into audio files for distribution

**Requires:** ElevenLabs API credentials
