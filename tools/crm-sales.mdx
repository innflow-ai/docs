## Airtable

Read from or write to Airtable bases. Use Airtable as a lightweight database for your workflows.

**Operations:**
- **List Records** — Fetch records from a table
- **Read Record** — Retrieve one record
- **Create Record** — Add a new record
- **Update Record** — Modify an existing record
- **Delete Record** — Remove a record

**Configuration:**

| Field | Description |
|-------|-------------|
| **Base ID** | Your Airtable base identifier |
| **Table ID** | The specific table within the base |
| **Fields** | Record field values (for Create/Update) |

**Requires:** Airtable OAuth connection

## HubSpot

Create, read, update, delete, list, and search HubSpot contacts, companies, deals, and other supported CRM records.

**Requires:** HubSpot OAuth connection

---

## Attio

Manage Attio CRM records, notes, tasks, and object metadata.

**Common operations:**

- List, get, search, update, delete, or assert records
- Create, read, list, and delete notes
- Create and list tasks
- Read object metadata

**Requires:** Attio connection

---

## Apollo

Search and enrich people or organizations, perform bulk enrichment, and create or update Apollo contacts.

**Requires:** Apollo API credentials
